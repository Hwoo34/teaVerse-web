# PRD — 차(茶) 정보 제공 WEB 기반 AI Agent 서비스

> 문서 버전: v1.0
> 작성일: 2026-09-18
> 프로젝트 코드명: **TeaVerse** (가칭)

---

## 1. 개요 (Overview)

> ⚠️ 교육용(학습·데모) 프로젝트입니다. 챗봇 답변·시드 데이터는 정확하지 않을 수 있습니다.

차(tea)에 대한 전문 정보를 카테고리별로 제공하고, 어느 페이지에서든 이용 가능한 플로팅 AI 챗봇을 통해 사용자의 차 관련 질문에 답변하는 웹 서비스.

- **프론트엔드**: React + TypeScript(Vite) 기반 SPA. 커스텀 디자인 시스템("모던 티 하우스") + framer-motion 애니메이션. S3 정적 호스팅(개발 중 로컬 → 최종 S3 배포)
  - 초기에는 Cloudscape로 골격을 잡았으나, 배포 수준의 트렌디한 UI/UX를 위해 커스텀 디자인 시스템으로 전환(번들 경량화 부수 효과).
- **백엔드**: Amazon Bedrock AgentCore 기반 멀티 에이전트 아키텍처
- **데이터**: 인터넷에서 수집 → S3 / DynamoDB / AgentCore Knowledge Base 에 저장, 주기적 자동 업데이트
- **인증**: Amazon Cognito (JWT). 챗봇 이용 시에만 로그인 필요, 정보 페이지는 비로그인 접근 가능

## 2. 목표 (Goals) 와 비목표 (Non-Goals)

### 2.1 목표
1. 전통차/중국차/한국차/꽃차 등 다양한 차에 대한 **전문 정보**를 카테고리 페이지로 제공.
2. **차 관련 전시 정보** 제공.
3. **차 상품 검색 및 연결**, 제품 리뷰·대중 선호 반응 분석 제공 (다구/다기/자사호 등 포함).
4. **트렌디·급부상 작가 정보**와 작가의 자사호·차 도구 상품 정보를 별도 페이지로 제공.
5. **플로팅 챗봇**을 모든 페이지에서 제공. DB 데이터 기반 답변 + 필요시 웹 검색(출처 표기).
6. 차 이외 주제에 대한 답변을 막는 **가드레일**.
7. 카테고리별 **데이터 수집·업데이트 에이전트**(24h 주기 + 관리자 온디맨드)와 **질의응답 에이전트** 운영.
8. **역할 기반 권한**: admin은 수집·업데이트 명령 가능, 일반 사용자는 불가.

### 2.2 비목표 (이번 범위 밖)
- 전자상거래 결제/장바구니 (상품은 "검색 및 외부 연결"까지만).
- 다국어 지원 (1차는 한국어 중심).
- 모바일 네이티브 앱.
- 실시간 재고/가격 보장 (수집 시점 스냅샷).

## 3. 사용자 및 역할 (Personas & Roles)

| 역할 | 계정 | 권한 |
|------|------|------|
| 게스트(비로그인) | - | 모든 정보 페이지 열람 가능. 챗봇 사용 불가 |

## 5. 기능 요구사항 (Functional Requirements)

### 5.1 정보 페이지 (F-INFO)
- **F-INFO-1**: 각 카테고리 페이지는 DB(S3/DynamoDB)에 저장된 데이터를 목록/상세로 렌더링.
- **F-INFO-2**: 검색/필터 (예: 차 종류, 지역, 가격대, 작가).
- **F-INFO-3**: 상품 페이지는 외부 상품 링크, 리뷰 요약, 선호도(감성분석) 지표 표시.
- **F-INFO-4**: 작가 페이지는 "급부상(rising)" 배지, 관련 상품 카드 표시.
- **F-INFO-5**: 비로그인 상태에서도 모든 정보 페이지 접근 가능.

### 5.2 챗봇 (F-CHAT)
- **F-CHAT-1**: 모든 페이지에서 접근 가능한 플로팅 위젯.
- **F-CHAT-2**: 로그인(JWT 유효) 상태에서만 대화 가능. 비로그인 시 로그인 유도.
- **F-CHAT-3**: 사용자의 차 관련 질문에 대해 DB 데이터 기반 답변.
- **F-CHAT-4**: DB에 없으면 웹 검색 도구로 조회 후 **출처(URL)** 와 함께 답변.
- **F-CHAT-5**: 차와 무관한 질문은 가드레일로 정중히 거절.
- **F-CHAT-6**: admin 계정은 "○○ 카테고리 데이터 지금 업데이트해줘" 같은 명령으로 수집 에이전트 트리거 가능. 비관리자는 거절.
- **F-CHAT-7**: 답변에 참조한 카테고리/데이터 출처를 함께 노출.

### 5.3 에이전트 / 데이터 (F-AGENT)
- **F-AGENT-1 (수집·업데이트 에이전트)**: 카테고리별로 존재. 인터넷 검색으로 최신 데이터 수집 → 정규화 → 저장소 반영. **24시간 주기** 자동 실행 + admin 온디맨드.
- **F-AGENT-2 (질의응답 에이전트)**: 카테고리별 tool 에이전트. 챗봇(오케스트레이터)이 Gateway 경유로 호출.
- **F-AGENT-3 (챗봇/오케스트레이터 에이전트)**: 사용자와 상호작용. Gateway를 통해 카테고리 에이전트에게 질의/검색. admin이면 수집 에이전트에 명령 라우팅.
- **F-AGENT-4**: 에이전트 간 통신은 Gateway 추상화를 통해 이루어짐.

### 5.4 인증·권한 (F-AUTH)
- **F-AUTH-1**: Cognito User Pool로 로그인, JWT(ID/Access token) 발급.
- **F-AUTH-2**: 챗봇 API 호출 시 JWT 검증. 유효하지 않으면 거부.
- **F-AUTH-3**: `admin` 그룹 클레임 여부로 수집·업데이트 명령 권한 판별.

## 6. 비기능 요구사항 (Non-Functional)

- **보안**: 자격증명/비밀은 소스/버킷에 노출 금지. S3 버킷 정책·CORS 최소 권한. 챗봇 API는 JWT 필수.
- **가드레일**: 주제 이탈·유해·프롬프트 인젝션 방어. (Bedrock Guardrails 또는 시스템 프롬프트+분류기)
- **관측성**: 에이전트 호출/수집 작업 로그 (CloudWatch).
- **비용**: 수집 주기 24h로 제한, 모델은 경량(Haiku 계열) 우선 + 필요시 Sonnet.
- **모델 제약 (필수)**: 에이전트 모델은 **Claude Sonnet 4.6 이하**만 사용한다. **Opus 이상(및 그 이상 등급) 사용 금지** — 비용 과다.
  - 기본(질의응답·수집·분류): `us.anthropic.claude-haiku-4-5-20251001-v1:0`
  - 상한(복잡한 오케스트레이션·추론): `us.anthropic.claude-sonnet-4-6`
  - 이 상한을 초과하는 모델(opus-*, sonnet-5, opus-5 등)은 코드/설정 어디에서도 지정하지 않는다.
- **성능**: 챗봇 첫 응답 목표 < 5s (스트리밍 시 첫 토큰 < 2s).
- **이식성**: 로컬(Docker)에서 프론트+에이전트 모킹 실행 → 동일 코드 클라우드 배포.

## 7. 데이터 도메인 (초안)

### 7.1 Tea (차)
`id, name, category(전통/중국/한국/꽃차), origin, description, brewing(온도/시간/횟수), flavorNotes[], caffeine, imageUrl, sources[]`

### 7.2 Exhibition (전시)
`id, title, venue, city, startDate, endDate, description, url, sources[]`

### 7.3 Product (상품)
`id, name, type(다구/다기/자사호/…), price, currency, vendor, url, imageUrl, rating, reviewSummary, sentiment(pos/neu/neg %), popularity, sources[]`

### 7.4 Artist (작가)
`id, name, rising(bool), bio, region, style, products[](refs), imageUrl, sources[]`

### 7.5 공통 메타
`lastUpdatedAt, updatedByAgent, sourceType(db/web)`

## 8. 수용 기준 (Acceptance Criteria) — 로컬 마일스톤

- [ ] 5개 페이지(홈/차정보/전시/상품/작가)가 로컬에서 데이터로 렌더링된다.
- [ ] 플로팅 챗봇이 모든 페이지에 뜬다.
- [ ] 비로그인 시 정보 페이지는 보이고, 챗봇은 로그인 유도한다.
- [ ] 로그인 후 챗봇이 차 질문에 DB 기반으로 답한다.
- [ ] DB에 없는 질문은 웹 검색 + 출처와 함께 답한다.
- [ ] 차와 무관한 질문은 거절한다(가드레일).
- [ ] admin 로그인 시 수집·업데이트 명령이 동작(모킹), 일반 사용자는 거절된다.
- [ ] 24h 주기 수집 스케줄 정의가 존재한다(로컬은 수동 트리거로 검증).
